### F4 — [stage-2] Document language is English while UI text is Ukrainian

- **Where:** `app/layout.tsx:27`; AC-10 (accessibility), ADR-0003
- **Problem:** `<html lang="en">` makes screen readers pronounce Ukrainian text as English (WCAG 3.1.1); axe does not catch this.
- **Suggested:** `<html lang="uk">`.
- **Verdict:** **Fix now**

### F5 — [stage-2] Removal dialog close button has an English label

- **Where:** `components/ui/dialog.tsx:75` (`sr-only` "Close"), rendered by `components/removePlantDialog.tsx:36`; ADR-0003, AGENTS.md §10
- **Problem:** the dialog's X button is announced as "Close" in English.
- **Suggested:** `showCloseButton={false}` on the removal dialog, or a `closeLabel` prop fed from `uiStrings`.
- **Verdict:** **Defer** — recorded in `spec.md` §8 (owner: Orest Lyubinets, due: before the next UI feature's sdd:review)

### F6 — [stage-2] Collection status uses a prohibited `aria-label` on `<p>`

- **Where:** `components/collectionStatus.tsx:10-11`; test `app/myGarden/page.test.tsx:37`; AC-10
- **Problem:** ARIA 1.2 prohibits `aria-label` on role paragraph; where honoured it would hide the counts behind the label; the test relies on it via `getByLabelText`.
- **Suggested:** wrap in `<section aria-label=…>` or add a visually hidden heading; query by role/text in the test.
- **Verdict:** **Fix now**

### F7 — [stage-2] Phone card does not guard a long unbroken type or location

- **Where:** `components/plantListItem.tsx:54-61`; AC-09
- **Problem:** below `md` the type/location spans sit in a non-wrapping flex row without `min-w-0` / `truncate` / `break-words`; a long single word can overflow at 360 px.
- **Suggested:** `min-w-0 truncate` (or `break-words`) on both spans at all widths, `flex-wrap` on the wrapper; cover with a test.
- **Verdict:** **Fix now**

### F8 — [stage-2] Contract notes and open questions stale after implementation
