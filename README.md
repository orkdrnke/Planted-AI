This is an MVP plant management app built with Next.js that experiments with AI-powered plant care recommendations. Users can add plants, browse them in a list, and view detailed pages where AI-generated care tips (watering, sunlight, general care) are attached asynchronously after creation. All data is currently stored client-side using Zustand, while AI generation is handled via a server-side API route to keep things secure. The project focuses on clean architecture, state management, and practical AI integration rather than being a fully featured gardening product.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
